# Ashen Concord: Founding

[Play against the trained AI](https://hmate9.github.io/ashen-concord-play/)

Four-player base Imperium with original Ashen Concord presentation. The game and
AI run in your browser. No installation, account, or GPU is needed.

[Download the compact model](downloads/imperium-compact-v1.zip) ·
[Model details and evaluation](MODEL_CARD.md) · [License](LICENSE)

This distribution contains the browser build and an experimental PPO-trained
opponent selected after a one-hour CPU campaign. Human-level strength has not
been established. This is an unofficial project, not affiliated with the owners
of Dune or Dune: Imperium. Third-party trademarks and artwork are not covered
by the code/model license.
